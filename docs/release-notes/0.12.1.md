**Suppa Browser 0.12.1** - a tiny, fast, private web browser for Windows and Linux.

### Fixed
- **Save video / Save as MP3**: getting the video tools failed with "The video tools could not be downloaded - yt-dlp: file not found". They now download and the video or MP3 is saved.

### New in 0.12
- Addresses, cards and PayPal filled in with one click; strong generated passwords; optional sync and sharing through Dropbox.
- A player button with a volume for each tab; Save video / Save as MP3; tabs kept awake; YouTube's Skip button pressed for you.
- Cookie popups: only necessary cookies by default. Languages: English, Русский, Deutsch, Español, 中文.
- Full details: the [0.12.0 release](https://github.com/Un1que0ff/suppa-browser/releases/tag/v0.12.0).

### Updating
- Installed with the setup: Suppa offers this update itself (or ≡ -> Help and updates -> Check for updates).

### Downloads
- **SuppaSetup.exe** (Windows, recommended): run it to install or update.
- **Suppa-0.12.1-windows-x64.zip** (Windows, portable): unpack and run `Suppa\Suppa.exe`.
- **Suppa-0.12.1-linux-x64.tar.gz** (Linux): unpack and run `sh install.sh`.

Windows needs Windows 10/11 64-bit with the WebView2 Runtime (the setup installs it if missing); SmartScreen may warn because the files are not code-signed (*More info -> Run anyway*). Linux needs WebKitGTK 4.1.
