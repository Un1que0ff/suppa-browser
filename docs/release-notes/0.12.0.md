**Suppa Browser 0.12.0** - a tiny, fast, private web browser for Windows and Linux.

### New
- **Addresses, cards and PayPal**: save several addresses, payment cards and PayPal accounts (Settings -> Addresses and payments, or when you send a form) and fill them in with the key button in form fields. Cards need Windows Hello; security codes (CVC) are never saved. Shops that offer PayPal get "Pay with PayPal instead".
- **Strong passwords**: sign-up forms get a generated password like `A%$3G&8^ga12Kq` that Suppa fills in and saves for the site (`Ctrl+Shift+G` copies one).
- **Sync and share with Dropbox** (optional, Settings -> Passwords): passwords, addresses and cards in one file encrypted with your passphrase.
- **Player and volume per tab**: a player button next to the downloads shows what plays (album cover, video preview) with play / pause, next and a volume slider for each tab, independent of the Windows volume. Tabs that play show a speaker (click = mute, `Ctrl+M`).
- **Save video / Save as MP3**: right-click a video or a YouTube page.
- **YouTube Skip button pressed for you** with a real click.
- **Keep awake**: right-click a tab so it never sleeps in the background.
- **Cookie popups**: only necessary cookies by default, "Accept all" if you prefer (Settings -> Privacy).
- **Languages**: English, Русский, Deutsch, Español, 中文 - the Windows language by default (Settings -> Appearance -> Language).
- **More shortcuts** like Chrome, Edge and Firefox; `F1` lists them.
- **Follows Windows**: new installs use the Windows light / dark mode and accent colour; the icon has no background (white on a dark Windows, black on a light one).
- The ≡ menu and Settings are sorted so everyday things come first.

### Updating
- Installed with the setup: Suppa offers this update itself (or ≡ -> Help and updates -> Check for updates).

### Downloads
- **SuppaSetup.exe** (Windows, recommended): run it to install or update.
- **Suppa-0.12.0-windows-x64.zip** (Windows, portable): unpack and run `Suppa\Suppa.exe`.
- **Suppa-0.12.0-linux-x64.tar.gz** (Linux): unpack and run `sh install.sh`. (The new features of this version are Windows-only for now.)

Windows needs Windows 10/11 64-bit with the WebView2 Runtime (the setup installs it if missing); SmartScreen may warn because the files are not code-signed (*More info -> Run anyway*). Linux needs WebKitGTK 4.1.
